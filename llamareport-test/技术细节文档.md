# LlamaReport Test 项目技术细节文档

## 📋 项目概述

**LlamaReport Test** 是一个基于 AI 的智能财务报告分析系统，支持 PDF 和 Excel 文档的上传、处理、智能问答和自动分析。系统采用前后端分离架构，使用 FastAPI + Vue.js 3 构建。

### 核心功能
- 📄 **多格式文档处理**: PDF、Excel (xlsx/xls)
- 🤖 **智能问答系统**: 基于 RAG (检索增强生成) 的文档问答
- 📊 **Agent 自动分析**: 使用 FunctionAgent 自动生成财务分析报告
- 📈 **数据可视化**: 交互式图表展示（Plotly.js）
- 🔍 **杜邦分析**: 财务指标深度分析
- 📝 **报告生成**: 自动生成企业概况、财务点评等结构化报告

## 📦 核心模块详解

### 1. 文档处理模块 (`core/document_processor.py`)

**功能**: 处理 PDF 和 Excel 文件，提取文本和表格数据

**技术实现**:
- **PDF 处理**:
  - 使用 `LlamaIndex PDFReader` 提取文档对象
  - 使用 `pdfplumber` 提取详细内容（文本、表格、元数据）
  - 为每个文档添加元数据（文件名、页码、文件类型）

- **Excel 处理**:
  - 使用 `ExcelProcessor` 处理 Excel 文件
  - 支持 `.xlsx` 和 `.xls` 格式
  - 提取表格数据和结构信息

**输出格式**:
```python
{
    'filename': str,
    'documents': List[Document],  # LlamaIndex Document 对象
    'detailed_content': dict,      # 详细内容（页面、表格等）
    'page_count': int,
    'total_text_length': int,
    'processing_method': str
}
```

### 2. RAG 引擎 (`core/rag_engine.py`)

**功能**: 构建向量索引，提供智能问答能力

**技术实现**:
- **LLM 配置**:
  - **DeepSeek**: 对话模型（`deepseek-chat`）
    - Temperature: 0.1（低温度保证稳定性）
    - API Key: `DEEPSEEK_API_KEY`
  
- **Embedding 配置**:
  - **OpenAI**: `text-embedding-3-small`
    - API Key: `OPENAI_API_KEY`
    - 维度: 1536

- **向量存储**:
  - ChromaDB 持久化存储
  - 集合名称: `documents`
  - 存储路径: `storage/chroma/`

- **文档分块**:
  - Chunk Size: 1024 字符
  - Chunk Overlap: 200 字符
  - 使用 `SimpleNodeParser` 进行分块

- **查询引擎**:
  - 默认使用 `VectorStoreIndex` 的查询引擎
  - 支持上下文过滤（按文件名等）
  - Top-K 检索: 5 个相似文档

**关键方法**:
```python
class RAGEngine:
    def build_index(self, documents: List[Document]) -> bool
    def query(self, question: str, context_filter: dict = None) -> dict
    def load_existing_index(self) -> bool
    def get_query_engine(self) -> QueryEngine
```

### 3. 混合检索器 (`core/hybrid_retriever.py`)

**功能**: 提供更精准的财务数据检索

**技术实现**:
- **混合评分机制**:
  - 语义相似度 (60%): 基于向量相似度
  - 指标匹配度 (30%): 财务指标关键词匹配
  - 年份一致性 (10%): 年份信息匹配

- **财务指标库**:
  - 内置常见财务指标关键词
  - 支持同义词匹配
  - 财务报表类型识别（利润表、资产负债表、现金流量表）

- **评分算法**:
```python
综合评分 = (
    语义相似度 × 0.6 +
    指标匹配度 × 0.3 +
    年份一致性 × 0.1
) + 财务报表加分
```

### 4. Report Agent (`agents/report_agent.py`)

**功能**: 使用 FunctionAgent 自动生成财务分析报告

**架构设计**:
```
用户查询
    ↓
ReportAgent (FunctionAgent)
    ↓
工具协调层
    ├─ QueryEngineTool (RAG 检索)
    ├─ FinancialReviewTool (财务点评)
    ├─ BusinessGuidanceTool (业绩指引)
    ├─ BusinessHighlightsTool (业务亮点)
    ├─ ProfitForecastTool (盈利预测)
    └─ DupontAnalysisTool (杜邦分析)
    ↓
结构化输出 (Pydantic Models)
    ↓
模板渲染 (Jinja2)
    ↓
Markdown 报告
```

**核心工具**:
1. **QueryEngineTool**: 基于 RAG 引擎的文档检索
2. **FinancialReviewTool**: 生成财务点评（财务图表、业绩速览、指标归因）
3. **BusinessGuidanceTool**: 生成业绩指引（业绩预告、经营计划、风险提示）
4. **BusinessHighlightsTool**: 生成业务亮点
5. **ProfitForecastTool**: 生成盈利预测和估值分析
6. **DupontAnalysisTool**: 杜邦分析（ROE、ROA、权益乘数）

**数据模型** (`models/report_models.py`):
- `AnnualReportAnalysis`: 完整报告模型
- `FinancialReview`: 财务点评模型
- `BusinessGuidance`: 业绩指引模型
- `BusinessHighlights`: 业务亮点模型
- `ProfitForecastAndValuation`: 盈利预测模型

### 5. 可视化 Agent (`agents/visualization_agent.py`)

**功能**: 自动识别查询意图，生成相应的数据可视化

**支持的可视化类型**:
- 折线图: 时间序列数据（如收入趋势）
- 柱状图: 分类对比（如各业务板块收入）
- 饼图: 占比分析（如收入结构）
- 表格: 结构化数据展示

**技术实现**:
- 使用 LLM 分析查询意图
- 从文档中提取相关数据
- 生成 Plotly.js 配置
- 返回前端可直接使用的 JSON 配置

### 6. 表格提取器 (`core/table_extractor.py`)

**功能**: 从 PDF 和 Excel 中提取结构化表格数据

**技术实现**:
- PDF 表格: 使用 `pdfplumber` 提取
- Excel 表格: 使用 `pandas` 读取
- 数据清洗和标准化
- 元数据标记（表格类型、位置等）

## 🔌 API 接口设计

### 1. 文件上传 API (`/upload`)

**POST `/upload/file`**
- 功能: 上传单个文件（PDF/Excel）
- 限制: 最大 50MB
- 返回: 文件信息（文件名、大小、类型）

**GET `/upload/list`**
- 功能: 获取已上传文件列表
- 返回: 文件列表（文件名、大小、上传时间）

**DELETE `/upload/file/{filename}`**
- 功能: 删除指定文件
- 返回: 删除结果

### 2. 文档处理 API (`/process`)

**POST `/process/file`**
- 功能: 处理单个文件，构建向量索引
- 参数: `filename`, `build_index` (bool)
- 返回: 处理摘要（页数、表格数、索引状态）

**POST `/process/files`**
- 功能: 批量处理文件
- 参数: `filenames` (List[str]), `build_index` (bool)
- 返回: 批量处理结果

**GET `/process/status`**
- 功能: 获取处理状态和索引状态
- 返回: 索引构建状态、文档数量等

### 3. 查询 API (`/query`)

**POST `/query/ask`**
- 功能: 智能问答（支持可视化）
- 参数:
  - `question`: 问题文本
  - `context_filter`: 上下文过滤（如按文件名）
  - `enable_visualization`: 是否启用可视化
- 返回:
  - `answer`: 回答文本
  - `sources`: 来源文档
  - `visualization`: 可视化配置（如果启用）

**POST `/query/quick-overview`**
- 功能: 快速生成企业概况
- 返回: 企业概况数据

**POST `/query/dupont-analysis`**
- 功能: 生成杜邦分析
- 参数: `company_name`, `year`, `filename`
- 返回: 杜邦分析结果（ROE、ROA、权益乘数等）

**GET `/query/suggestions`**
- 功能: 获取推荐问题
- 返回: 问题建议列表

### 4. Agent API (`/agent`)

**POST `/agent/query`**
- 功能: Agent 智能分析查询
- 参数: `question`: 分析问题
- 返回:
  - `status`: 状态（success/error）
  - `answer`: 分析结果
  - `tool_calls`: 工具调用记录
  - `visualization`: 可视化数据
  - `structured_response`: 结构化响应
  - `performance`: 性能指标

**POST `/agent/generate-report`**
- 功能: 生成完整年报分析报告
- 参数: `company_name`, `year`, `save_to_file`
- 返回: 报告生成状态和内容

**POST `/agent/generate-section`**
- 功能: 生成报告特定章节
- 参数: `section_name`, `company_name`, `year`
- 返回: 章节内容

## 🔄 数据流程

### 1. 文档上传和处理流程

```
用户上传文件
    ↓
FastAPI 接收 (upload.py)
    ↓
保存到 uploads/ 目录
    ↓
DocumentProcessor 处理
    ├─ PDF: PDFReader + pdfplumber
    └─ Excel: ExcelProcessor
    ↓
生成 LlamaIndex Document 对象
    ↓
RAGEngine.build_index()
    ├─ 文档分块 (1024 chars, 200 overlap)
    ├─ 生成 Embedding (OpenAI)
    └─ 存储到 ChromaDB
    ↓
索引构建完成
```

### 2. 查询流程

```
用户提问
    ↓
前端发送 POST /query/ask
    ↓
RAGEngine.query()
    ├─ 生成查询 Embedding
    ├─ ChromaDB 向量检索 (Top-K=5)
    ├─ HybridRetriever 混合评分
    └─ 上下文过滤（如按文件名）
    ↓
DeepSeek LLM 生成回答
    ├─ 输入: 问题 + 检索到的文档
    └─ 输出: 回答文本
    ↓
可视化 Agent 分析（可选）
    ├─ 识别可视化需求
    ├─ 提取数据
    └─ 生成 Plotly 配置
    ↓
返回结果给前端
```

### 3. Agent 分析流程

```
用户发起 Agent 查询
    ↓
POST /agent/query
    ↓
ReportAgent 初始化
    ├─ 加载 RAG 查询引擎
    └─ 初始化 FunctionAgent
    ↓
Agent 分析用户意图
    ↓
选择并调用工具
    ├─ QueryEngineTool: 检索文档
    ├─ FinancialReviewTool: 生成财务点评
    ├─ BusinessGuidanceTool: 生成业绩指引
    ├─ BusinessHighlightsTool: 生成业务亮点
    ├─ ProfitForecastTool: 生成盈利预测
    └─ DupontAnalysisTool: 杜邦分析
    ↓
工具返回结构化数据 (Pydantic Models)
    ↓
Agent 整合结果
    ↓
TemplateRenderer 渲染（如需要）
    ↓
返回结构化响应
```
